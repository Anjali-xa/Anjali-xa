# 📱 Telecom Customer Usage Analysis

Explore telecom customer usage analysis data and develop evidence-based business insights.

**Tools:** SQL · Python · Power BI

## Included
- `data/sample.csv`: synthetic demonstration rows only.
- `analysis.py`: pandas profiling starter.
- `sql/analysis.sql`: starter SQL queries.

## Analysis workflow
1. Replace the demo file with a documented public dataset and cite its source.
2. Validate data types, missing values, duplicates and outliers.
3. Define KPIs; analyse trends and segments.
4. Build visualisations and a Power BI dashboard where applicable.
5. Add verified insights, recommendations and dashboard screenshots.

**Data disclaimer:** sample rows are synthetic, not real-world evidence or official statistics. Do not draw or publish factual conclusions from them.

## Run
```bash
pip install pandas
python analysis.py
```
