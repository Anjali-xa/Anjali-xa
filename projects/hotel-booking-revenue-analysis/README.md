# 🏨 Hotel Booking & Revenue Analysis

Explore hotel booking patterns, cancellations and room revenue using a reproducible analytics workflow.

**Tools:** Excel · SQL · Python · Power BI

## Included
- `data/sample.csv`: synthetic demonstration rows only.
- `analysis.py`: pandas profiling starter.
- `sql/analysis.sql`: starter SQL queries.

## Workflow
1. Replace demo data with a documented public dataset and cite its source.
2. Validate data types, missing values, duplicates and outliers.
3. Define KPIs; analyse booking lead time, cancellations and revenue.
4. Build charts and a Power BI dashboard.
5. Add verified insights, recommendations and dashboard screenshots.

**Data disclaimer:** sample rows are synthetic, not official statistics or real-world evidence. Do not publish factual conclusions from them.

## Run
```bash
pip install pandas
python analysis.py
```
