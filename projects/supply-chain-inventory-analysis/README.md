# 📦 Supply Chain & Inventory Analysis

Track stock levels, reorder needs, supplier lead times and fulfilment performance.

## Project goals
- Clean and validate the source data.
- Define useful business questions and KPIs.
- Explore trends, categories and outliers.
- Communicate findings with clear charts and a dashboard.

## Tools
Python · SQL · Excel · Power BI

## Repository structure
- `data/sample.csv` — small **synthetic demo** dataset to test the workflow.
- `analysis.py` — starter Python exploration script.
- `sql/analysis.sql` — starter SQL queries (adapt table and column names to your database).

## Important data note
The included rows are synthetic examples created for project scaffolding. They are not official statistics and must not be presented as real-world findings. Replace them with a documented public dataset before drawing conclusions or publishing a final dashboard.

## Suggested business questions
- What are the strongest and weakest segments?
- Which factors appear associated with the main outcome?
- How does performance vary by category, location or time?
- What operational action could the analysis support?

```bash
pip install pandas
python analysis.py
```
